# Test Plan Skill

Create a testing plan before implementation.

## Goal

Define what needs to be tested and how:
- Unit test modules
- Integration test cases
- Edge cases
- Test data setup

## Actions

1. Read the handoff file (including plan)
2. Read relevant source files for test patterns
3. Write the test plan in the handoff
4. Set Status to `tplan`

## Output

Test plan in handoff Section 5.
