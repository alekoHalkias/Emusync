# Design Skill

Define the design for the proposed change.

## Goal

Analyze the issue and produce a design document covering:
- Scope and constraints
- Technical approach
- Risk assessment
- Difficulty rating (1-10)
- Breaking change assessment
- Recommendation: fplan or bplan

## Actions

1. Read the handoff file and issue
2. Read relevant project docs (CLAUDE.md, ARCHITECTURE.md, GOTCHAS.md)
3. Write the design section in the handoff file
4. Set Status to `design`
5. If the problem seems straightforward, recommend `fplan`. If complex, recommend `bplan`.

## Output

Design document in handoff Section 2.
