# Backend Plan Skill

Create a detailed backend plan with step-by-step implementation.

## Goal

Write a comprehensive plan covering:
- Implementation steps (numbered, executable)
- File locations and dependencies
- Testing strategy
- Edge cases
- Schema/API changes if applicable

## Actions

1. Read the handoff file (including design)
2. Read relevant source files for context
3. Write the backend plan in the handoff file
4. Set Status to `bplan`

## Output

Detailed backend plan in handoff Section 3.
