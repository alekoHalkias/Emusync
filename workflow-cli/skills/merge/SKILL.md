# Merge Plan Skill

Merge the frontend and backend plans (if both are needed).

## Goal

When a change requires both frontend and backend work, create a unified plan that combines both perspectives.

## Actions

1. Read both fplan and bplan sections from the handoff
2. Identify shared steps and dependencies
3. Create a merged plan in the handoff
4. Set Status to `merge`

## Output

Merged plan in handoff Section 4.
